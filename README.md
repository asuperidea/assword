# Assword
Open Source Local Password Manager.

## How It Works
The database and api run on your computer. It's tunneled to any url you want.

You use the frontend to securely store passwords (or anything) to the backend.

## On my computer
(My Assword)[https://assword.simoncrystal.dev] is up for anyone to use. Because of the client-side encryption I can see none of your passwords.
